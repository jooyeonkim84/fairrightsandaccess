-------------------------------------

 HDD Restore CD README

 -------------------------------------

 

------------------

HOW TO USE THIS CD

------------------

You can use the Restore CD when the following case:

Case l : To restore the system to original factory configuration.

Case 2 : To reinstall lost or destroyed drivers or application programs.

Case 3 : To read the user's guide

 

 

Case 1 : To restore the system to original factory configuration

---------------------------------------------------------------

Follow the next steps :

 

1. Boot your system and insert the restore CD into the CD-ROM drive.

   Note : Because this CD is bootable, check whether the 1st boot device is ATAPI CD-ROM

          in the setup menu and insert this before boot from HDD

  

2. When the following menu appears, choose '1' or '2' and press 'Enter' key.

Microsoft Windows 98 Startup Menu

---------------------------------

     1. RESTORE WINDOWS 98 - WILL FORMAT HDD

2. RESTORE WINDOWS 98 - WILL NOT FORMAT HDD

3. BOOT TO DOS PROMPT FROM CD ROM

Enter a choice (3=DEFAULT): 3

 

Warning:

Option 1 will remove all HDD data before restoring the system to original factory

 configuration.

Option 2 will overwrite only Windows 98 information. This procedure may not succeed

 in some cases. Exisiting programs may need to be reloaded. If this procedure dose

 not succeed, it will be required to rerun the restore, using option 1.

  Option 2 Expert use only - will boot to a dos prompt

 

To stop this restore process now, remove the resotre CD from the CD-ROM drive and

restart your computer. [Turn computer off, wait 15 secs, then turn back on]

 

3. The case of option 1, it checks whether you want to format HDD.

4. The next procedure is automatic.

5. After the restoration procedure is complete, press 'Enter' key and remove the restore CD

   from your CD-ROM drive.

6. Windows 98 starts and the mouse tutorial program runs.

 

Case 2 : To Install drivers or application programs

---------------------------------------------------

Follow the next steps :

 

1. Insert the Restore CD into the CD-ROM drive when Windows 98 is running.

2. If you insert the Restore CD into the CD-ROM drive, the autorun program runs.

3. Click the driver or the application program that you want to install.

 

Note: Refer to the following to install the drivers or application programs.

      If Windows 98 needs to restart, remove the resotre CD from the CD-ROM drive before

      restarting.

 

Drivers

-------

Note : If D is not the CD-ROM drive, substitute D with the correct drive letter.

 

Video Driver D:\drivers\video\setup.exe

Note : This setup requires to restart Windows 98, so you had better close any programs

you have running.

 

Audio Driver D:\drivers\audio\setup.exe

Note : This setup requires to restart Windows 98, so you had better close any programs

you have running.

When Windows 98 restarts, the 'Add new hardware wizard' runs to install audio driver.

When the wizard searchs for the device driver for audio, click 'Next' to continue.

The next, select 'Search for the best driver for your device' and click 'Next'

to continue.

The next, select 'Specify a location' and search the location(e.g. D:\drivers\audio)

for the audio driver using 'Browse' and click 'Next' to continue.

When the wizard searchs for the driver file, click 'Next' to continue.

If the wizard dose not search for the driver file, click 'Back' to search the

other location for the driver again.

The next, click 'Finish' and then the installation of the audio driver is complete.

 

Modem Driver   D:\drivers\modem\HsfDFen.inf

  Note : If the modem driver is destroyed or removed, the 'Add new hardware wizard'

       runs to install the device driver when Windows 98 starts or the information of

system device is refreshed.

When the wizard searchs for the device driver for modem, click 'Next' to continue.

The next, select 'Search for the best driver for your device' and click 'Next'

to continue.

The next, select 'Specify a location' and search the location(e.g. D:\drivers\modem)

for the modem driver using 'Browse' and click 'Next' to continue.

When the wizard searchs for the driver file, click 'Next' to continue.

If the wizard dose not search for the driver file, click 'Back' to search the

other location for the driver again.

The next, click 'Finish' and then the installation of the modem driver is complete.
